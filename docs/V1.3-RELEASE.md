# v1.3 Release Notes

## Highlights

1. Added 20 new interactive button presets, bringing the gallery from 44 to 64 total.
2. New styles cover ten design directions: Cyberpunk, Glass, 3D/Skeuomorphic, Neo-Brutalism, Neumorphism, Aurora, Luxury Minimal, Retro Pixel, Micro-Interactions, and Playful.
3. Added a shared signature-preset collection with dedicated live preview styling and standalone CSS export behavior for every new design.
4. Updated the hero count, README, package metadata, and registry contract test to 64 presets.
5. Existing favorites, search, filtering, pagination, customization, sound and code export workflows remain compatible.
