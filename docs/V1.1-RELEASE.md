# v1.1 Release Notes / QA Status

## Delivered

1. React modal hooks fixed using conditional mounting.
2. Shared export normalization for icon placement, text, size, radius, border, states, disabled, animation speed. Escaped user text prevents HTML injection.
3. 24 presets extracted into individual files and registry.
4. `supportedControls()` provides a capability contract for future per-preset control tuning.
5. Gallery hover/press interaction constrained to previewed button area; Studio gets hover and press state.
6. Favorites remain preset IDs; separately saved customized variants persist locally and are listed in drawer, included in CSS bundle.
7. Vitest contract tests for registry/export shape; add visual golden tests for pixel parity before publishing.
8. Added ESLint, Prettier, TypeScript check, CI, and QA scripts.
9. Removed obsolete AI Studio dependencies/metadata, updated README and package version, added MIT license.
10. Added reduced motion, dialog focus/escape support, URL query deep-link `?button=<id>`.

## Limitations / verification needed

- Export parity is **functional**, not pixel-perfect: generated HTML/CSS/React/Tailwind cannot reproduce every complex React DOM animation precisely. React and Tailwind snippets need the CSS tab output.
- `iconName` in standalone export is a readable text icon marker instead of a Lucide SVG; consumers may replace it with an icon library.
- Customizer control metadata exists but the original UI still renders most controls for each preset.
- Saved variants support persistent storage and CSS copying, not loading back into Studio for editing.
- Static link `?button=id` works on normal hosting; `/buttons/id` requires host SPA rewrites.
- `npm install`, end-to-end browser tests and full build were not verified in the current environment because registry fetch timed out; run `npm install && npm run qa` in a networked Node 22 environment.
