# ButtonCraft v1.1.1 — dependency and QA stabilization

- Use Node.js >=20.19.0 (recommended Node 22 LTS) and npm >=10.
- Replace speculative dependency versions (Vite 8, TypeScript 7 and newer plugin versions) with the tested-in-ecosystem Vite 6 / TypeScript 5.8 / React 19 series.
- Remove AI Studio-specific configuration in `vite.config.ts`.
- Use explicit npm install in CI until a lockfile can be generated against an accessible npm registry.
- `.npmrc` disables optional audit/fund network calls.

## Commands

```bash
npm install
npm run qa
npm run dev
```

If a previously failed install left old dependencies, delete `node_modules` and `package-lock.json` first, then run `npm install` again.

## Verification limitations

The authoring environment cannot resolve registry.npmjs.org (`EAI_AGAIN`). Therefore dependency installation, typecheck, lint, Vitest, and Vite build **cannot be confirmed to pass in this environment**. A valid `package-lock.json` could not be generated; npm will create it during first successful install. This is a source-level remediation, not a verified green CI release.
