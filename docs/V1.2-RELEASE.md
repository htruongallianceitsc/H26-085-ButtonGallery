## Notes

- Every new preset follows the existing `ButtonDefinition` contract (css/html/tailwind/react generators + `render`) and is wrapped by `enhancePreset()` like the original 24, so export normalization and control support behave identically.
- None of the new `render` implementations use React hooks, consistent with the rest of the preset set and required by the `react-hooks/rules-of-hooks` ESLint rule (the `render` field is a plain callback, not a recognized component/hook name).
- Same known limitation as v1.1: exported HTML/CSS/React/Tailwind is functional, not pixel-perfect, for presets with complex layered animation.
